# Полка: лендинг

Одностраничный сайт. Статический HTML, без сборки и зависимостей: шрифты подгружаются с Google Fonts.

## Как подключить Google Форму

Откройте `index.html` и найдите блок `CONFIG` в начале скрипта.

1. Создайте Google Форму с полями: география, количество торговых точек, форматы сетей (флажки ММ, СМ, ГМ), потребность в персонале, контакт.
2. Скопируйте ссылку формы вида `https://docs.google.com/forms/d/e/ID/viewform` в `formUrl`.
3. Чтобы поля заполнялись автоматически: в форме нажмите «⋮ → Получить ссылку для предварительного заполнения», заполните каждое поле любым значением, нажмите «Получить ссылку». В полученной ссылке у каждого поля будет параметр `entry.123456789`. Числа впишите в `fields`:

```js
var CONFIG = {
  formUrl: "https://docs.google.com/forms/d/e/ID/viewform",
  fields: { geo: "111", count: "222", formats: "333", staff: "444", contact: "555" }
};
```

Без `fields` форма откроется пустой, а текст заявки скопируется в буфер обмена.

Пока `formUrl` пустой, кнопка «Оставить заявку» показывает сообщение, что приём заявок скоро заработает.

## Публикация

Сайт отдаётся через GitHub Pages из ветки `main`, корень репозитория.
